One-time setup

      
    
        
  1. Create the repository. On GitHub, click + → New repository. Name it bell-schedules, set it to Public, tick "Add a README file", and click Create. Public is required: students' extensions read this file without signing in, and it contains nothing but bell times.
    2. 
        
  2. Turn on GitHub Pages. In the repo, go to Settings → Pages. Under "Build and deployment", set Source to Deploy from a branch, branch main, folder / (root), then Save. After a minute your files are live at https://YOURNAME.github.io/bell-schedules/.
    3. 
        
  3. Upload this editor. In the repo's Code tab, click Add file → Upload files, drag in schedule-editor.html, and commit. From then on, open the editor at https://YOURNAME.github.io/bell-schedules/schedule-editor.html. Saving to GitHub only works from there or from your own computer — not from the preview link in chat.
    4. 
        
  4. Create an access token. On GitHub go to your profile photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Set: name anything, expiration 90 days, Repository access → Only select repositories → pick bell-schedules, then Permissions → Repository permissions → Contents: Read and write. Generate, then copy the token — GitHub shows it once.
    5. 
        
  5. Connect the editor. On the Publish tab, fill in your owner name, repo, branch main, path overrides.json, paste the token, and click Save connection. The token stays in this browser's local storage and is never sent anywhere except GitHub.
    6. 
        
  6. Build your schedules. Add your school, create templates for a normal day and any special days, map the normal week, then paint special dates on the calendar. Click Save to GitHub when done.
    7. 
      

      
Prefer not to use a token? Click Download JSON instead, then in the repo use Add file → Upload files and drop it in. Same result, one more step each time.

      
When the token expires, saving fails with a 401. Generate a new one the same way and paste it in again.

    

    

      
How the file is structured

      
Every day is a template. The normal week maps weekdays to templates; the calendar overrides individual dates. A template with an empty period list means no school, which covers holidays without a special case. Because the regular schedule lives here too, adding a school never requires a new version of the extension.
